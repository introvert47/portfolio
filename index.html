What I'm most proud of

A personal AI assistant that remembers you

A password-protected assistant that actually remembers your conversation — I store chat history in a Cloudflare D1 database instead of losing it on refresh, and connected it to Gmail and Calendar so it can check your schedule or draft an email when you ask.

Cloudflare Workers Cloudflare D1 Vercel Gmail & Calendar API
How a message moves through it:
1. Vercel frontend Password gate, chat UI
2. Cloudflare Worker Handles the request
3. Cloudflare D1 Saves the conversation
4. Google APIs Gmail & Calendar, on request
